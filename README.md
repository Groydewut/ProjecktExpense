

# 🚀 Инструкция по развертыванию и запуску проекта

Данное руководство поможет вам быстро настроить окружение, развернуть базу данных и запустить приложение **CLIExpense** (Go + PostgreSQL + Vanilla JS) на любом компьютере.

---

## 📋 Требования к окружению

Перед началом убедитесь, что у вас установлены:

* **Go** (версии 1.20 или новее)
* **PostgreSQL** (локально или в Docker)
* Любой современный браузер

---

## 🛠️ Пошаговая настройка

### Шаг 1. Создание базы данных и таблиц

Так как в приложении не используется автоматическая миграция, структуру базы данных необходимо развернуть вручную.

1. Откройте ваш клиент базы данных (pgAdmin, DBeaver, CLI `psql`) и создайте пустую БД с именем `expense_db`.
2. Выполните следующий SQL-скрипт для создания таблиц пользователей и расходов с необходимыми индексами:

```sql
-- 1. Таблица пользователей (хранит аккаунты и хэши паролей)
CREATE TABLE IF NOT EXISTS users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash TEXT NOT NULL
);

-- 2. Таблица расходов (жестко привязана к пользователю через внешний ключ)
CREATE TABLE IF NOT EXISTS expenses (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    price NUMERIC(10, 2) NOT NULL,
    category VARCHAR(100) NOT NULL
);

-- Индекс для ускорения выборки трат по конкретному пользователю
CREATE INDEX IF NOT EXISTS idx_expenses_user_id ON expenses(user_id);

```

> ⚠️ **Важно:** Связка `ON DELETE CASCADE` гарантирует, что при удалении пользователя из базы данных автоматически и безболезненно удалятся все его расходы, не засоряя память.

---

### Шаг 2. Конфигурация переменных среды (`.env`)

Для безопасности бэкенд не хранит доступы к базе внутри кода, а считывает их из конфигурационного файла.

1. В **корневой папке** проекта (там, где лежит `main.go`) создайте файл с именем `.env`.
2. Скопируйте и заполните в него следующие параметры:

```env
# Настройки подключения к вашей СУБД PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_NAME=expense_db
DB_SSLMODE=disable

# Секретный ключ для шифрования и подписи сессий (JWT-токенов)
JWT_SECRET=придумайте_сложную_случайную_строку_для_безопасности

```

---

### Шаг 3. Проверка структуры папок

Сервер Go настроен на раздачу фронтенда по относительному пути `./frontend`. Чтобы статика (HTML/CSS/JS) успешно загрузилась, структура файлов в корне папки **CLIExpense** должна строго соответствовать схеме:

```text
CLIExpense/
├── frontend/          # Папка с визуальным интерфейсом
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── .env               # Созданный вами файл конфигурации
├── go.mod
├── go.sum
└── main.go            # Главный файл запуска бэкенда

```

---

### Шаг 4. Установка зависимостей и запуск проекта

1. Откройте терминал в корневой папке проекта (`CLIExpense`).
2. Очистите и обновите внешние зависимости Go (скачаются роутер `chi`, `godotenv` и др.):
```bash
go mod tidy

```


3. Запустите сервер:
```bash
go run main.go

```


4. В консоли должно появиться сообщение: `Сервер запущен на http://localhost:8080`.
5. Откройте любимый браузер и перейдите по адресу: **`http://localhost:8080`**

## Важные подводные камни (Частые проблемы)

* **Порт базы данных:** Если у вас PostgreSQL запущен в Docker или на MacOS, стандартный порт `5432` может быть занят. Не забудьте поменять его в файле `.env` на правильный (например, `5433`).
* **Кэширование фронтенда:** Если вы вносили изменения в стили или скрипты фронтенда, а в браузере ничего не поменялось — обновите страницу с полной очисткой кэша с помощью комбинации клавиш **`Ctrl + F5`** (или `Cmd + Shift + R` на Mac).
* **Хэширование паролей:** Бэкенд ожидает, что при регистрации пароли хэшируются стандартным алгоритмом `bcrypt` перед сохранением в `password_hash`. Ввод «голого» пароля напрямую в БД вручную не позволит пользователю войти через веб-интерфейс.
