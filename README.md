# 💰 CLIExpense — Веб-приложение для учёта личных расходов

**CLIExpense** — это минималистичное и производительное fullstack-приложение для ведения личного бюджета. Проект предоставляет удобный веб-интерфейс с авторизацией, защитой данных и полной изоляцией расходов между пользователями.

Проект полностью упакован в **Docker** и готов к развертыванию в одну команду.

---

## 🌟 Основной функционал

### 🔐 Авторизация и безопасность

* **Регистрация и вход:** Создание личного аккаунта с защитой паролей (хэширование алгоритмом `bcrypt`).
* **JWT-авторизация:** Использование JSON Web Tokens для безопасного доступа к API без необходимости хранить сессии на сервере.
* **Изоляция данных:** Каждый пользователь имеет доступ **строго к своим собственным расходам**. Никто другой не может просмотреть или изменить чужие записи.

### 📊 Управление расходами

* **Просмотр расходов:** Отображение списка всех трат пользователя с указанием названия, категории и стоимости.
* **Добавление записей:** Удобная форма для оперативного внесения новых трат.
* **Удаление трат:** Быстрое удаление ненужной записи в один клик.
* **Автоматический подсчет:** Мгновенный перерасчёт и отображение **общей суммы всех трат** пользователя в режиме реального времени.

---

## 🛠️ Технологический стек

* **Backend:** Go (Golang), HTTP-роутер [go-chi](github.com/go-chi/chi), JWT (golang-jwt).
* **Database:** PostgreSQL (реляционная БД с внешними ключами и каскадным удалением).
* **Frontend:** Vanilla JavaScript (ES6+, Fetch API), HTML5, CSS3 (без громоздких фреймворков, чистая и быстрая загрузка).
* **DevOps:** Docker, Docker Compose.

## 🚀 Быстрый запуск (через Docker)

Для запуска приложения на любой машине понадобятся только установленные **Docker** и **Docker Compose**.

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/Groydewut/ProjecktExpense.git
cd CLIExpense

```


2. **Запустите контейнеры:**
```bash
docker-compose up --build -d

```


*Docker автоматически соберет Go-сервер, поднимет PostgreSQL и применит необходимые настройки.*

3. **Откройте приложение:**
Перейдите в браузере по адресу: **`http://localhost:8080`**

## 📡 REST API Эндпоинты

Приложение предоставляет следующие API-ручки:

| Метод | Путь | Описание | Защита авторизацией |
| --- | --- | --- | --- |
| `POST` | `/register` | Регистрация нового пользователя | ❌ |
| `POST` | `/login` | Вход и получение JWT-токена | ❌ |
| `GET` | `/expenses` | Получение списка всех трат текущего пользователя | ✅ |
| `POST` | `/expenses` | Добавление новой траты | ✅ |
| `DELETE` | `/expenses/{id}` | Удаление траты по ее ID | ✅ |
| `GET` | `/total` | Получение общей суммы трат пользователя | ✅ |
